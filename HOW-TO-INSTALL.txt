ONTECHBOT - INSTALLABLE APP (Windows, Mac, Linux, Android, iPhone)

STEP 1 - PUT IT ONLINE (free, 3 minutes, needed once)
Installing needs a secure web address (https). You already use Cloudflare, so:
1. Go to dash.cloudflare.com > Workers & Pages > Create > Pages > "Upload assets".
2. Name the project (for example ontechbot-app).
3. Drag in the whole contents of this folder (index.html, sw.js, manifest.webmanifest, _headers and the icons folder). Click Deploy.
4. Cloudflare gives you an address like https://ontechbot-app.pages.dev . That is your app.

STEP 2 - INSTALL IT
Android (Chrome): open the address > tap the "Install" button at the top of the app (or menu > Install app).
iPhone / iPad (Safari only): open the address > Share button > Add to Home Screen > Add. (The Install button in the app shows these steps.)
Windows / Mac / Linux (Chrome or Edge): open the address > click the "Install" button in the app, or the install icon at the right end of the address bar.
After that it opens in its own window with its own icon, and works offline (past papers, quizzes, exams). The AI answers need internet.

UPDATING LATER
Upload the new files to the same Cloudflare Pages project. Installed apps show "A new version is ready - Update now".

OPTIONAL
- Lock your AI to your app: in the Cloudflare Worker settings add the variable ALLOWED_ORIGIN = your pages.dev address.
- Real store files (.apk / .aab for Google Play, .msix for Microsoft Store): go to pwabuilder.com, paste your address and download the packages. The Apple App Store needs a Mac and a paid Apple developer account.
- Voice features need Chrome or Edge, and the browser asks for microphone permission once.
